# Checks

Engine collision and interaction checks plus a fixed-camera draw-call comparison. From the root use `godot --headless --path gallery --script res://checks/check_scene.gd` or `godot --path gallery --resolution 900x650 --disable-vsync --script res://checks/profile_scene.gd`. Start with [this file](check_scene.gd).
